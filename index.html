Six fixes, one pass

Everything below runs on your own machine, against your own config вЂ” nothing is uploaded and no game files are replaced.

01

Texture cache rebuild

Clears and rebuilds the streaming cache so textures stop popping in late or staying blurry. The new cache is written from scratch, which resolves most "everything looks like a painting" sessions.

02

LOD tuning

Raises the draw distance for level textures so distant streets stop looking like mush. It works inside the safe range of the engine, so far geometry keeps its detail without a full texture overhaul.

03

Pop-in fix

Reduces texture and geometry pop-in on fast travel and driving. Streaming is spread more evenly across frames, so assets arrive before the camera reaches them instead of snapping in behind you.

04

VRAM memory tweak

Adjusts streaming budgets for low and high memory GPUs. Cards with 6 GB get a conservative profile that avoids thrashing, while 12 GB and up get headroom for sharper close-range detail.

05

Config backup

A timestamped copy of the current settings is written before any change. Roll back with one click or by restoring the file by hand вЂ” every run keeps its own snapshot, so nothing is ever overwritten silently.

06

Portable and offline

One folder, no account, no telemetry. Run it from a USB stick, close it, delete it вЂ” there is no background service, no driver, and no network call at any point.

Straight answers

The short version: it touches settings and cache, never the game itself. Full details live in the repository docs.

Will this fix blurry textures on a low-end GPU?

It helps most where blur is caused by streaming pressure rather than raw horsepower. A rebuilt cache plus a conservative VRAM budget removes the late-arriving low-resolution mips that make surfaces look smeared. On 4 GB cards expect cleaner close-ups and fewer pop-in spikes, not a free resolution upgrade.

Does it replace or modify game files?

No. It only reads and writes your local settings and texture cache, and it makes a timestamped backup first. No archives are repacked, no executables are patched, nothing is injected into the process.

Which versions of the game are supported?

Any current PC build that keeps its config in the standard user settings folder. If a game update moves those paths, the tool reports it instead of writing to a guess, so a broken profile never happens quietly.

How long does a cache rebuild take?

The deletion is instant; the game rebuilds the cache while you play. Give it one long session with a slow drive around the city before judging the result вЂ” the first few minutes can look worse while new assets stream in.

Can I undo the changes?

Yes. Every run stores a timestamped copy of the previous settings next to the tool. Restore the newest snapshot and the original values are back; delete the cache folder and the game simply builds a fresh one.

Is an account, installer or internet connection needed?

None of them. Unzip one folder, run the utility, done. There is no login, no installer, no updater and no telemetry вЂ” the tool never opens a network connection.
